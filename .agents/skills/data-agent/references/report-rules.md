# 报告规则

报告规格保存为 `report/report.json`：

```json
{"title":"报告标题","date":"2026-09-21","analyst":"分析师","summary":["有数据依据的核心结论"],"sections":[{"title":"趋势分析","paragraphs":["结论先行的分析文字"],"source":"result.csv"}]}
```

- 每个结论必须能在 `data/*.csv` 中找到或通过明确公式计算。
- 不确定的因果关系使用“可能”“需进一步验证”，不能写成确定事实。
- 比率聚合优先使用分子/分母重算，不得默认对百分比做简单平均。
- 报告包含数据范围、来源文件、SQL 文件和生成时间。
- HTML 仅由内置生成器组装，禁止注入未经转义的 HTML。
