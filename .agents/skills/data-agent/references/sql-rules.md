# SQL 生成与验证规则

证据优先级：已审核长期记忆和历史 SQL；Hive 表结构与建表脚本；Tableau 官方报表口径和默认筛选器；本次会话的数据探查。字段、枚举值、JOIN 键没有证据时，先探查并让用户确认。

- `df` 快照表使用单个 `dt = 'yyyyMMdd'` 分区；业务日期用实际业务字段过滤。
- `di` 增量表必须限制 `dt` 范围。
- COUNT 类行为指标同时检查时间非空和成功状态、正金额等业务条件。
- 继承来源 Tableau 报表的默认筛选器，除非用户明确覆盖。
- 多表 JOIN 明确粒度，防止一对多放大；最终结果限制行数。
- 先用小范围或 EXPLAIN 验证，再执行完整查询。
- 关键口径或字段缺失时可信度为低；低可信度不得执行正式查询。
