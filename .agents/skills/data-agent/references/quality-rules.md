# 质量检查

## 确定性错误

- 表或字段经知识库/元数据确认不存在。
- SQL 非只读、多语句、缺少必要分区，或语法验证失败。
- 明确要求的核心指标、维度或筛选条件缺失。
- 数据文件为空、缺表头或报告引用不存在的数据。
- 报告结论与 CSV 明显矛盾。

确定性错误状态为 `blocked`，修复后才能继续。

## 警告

- 知识库没有找到表，但无法确认其不存在。
- SQL 没有 LIMIT、使用 `SELECT *`，或结果可能被截断。
- 比率超出 0–1、金额为负、时间范围接近但不完全匹配。
- 口径存在多种合理解释、缺少非核心维度或数值偏离经验范围。

警告状态为 `warning`；明确说明影响并由用户决定是否调整。

## 审计范围

- `request`：需求文件与 SQL 的覆盖关系。
- `sql`：只读安全、表、字段、分区、粒度、口径和 LIMIT。
- `data`：完整性、截断、范围与异常值。
- `report`：数据引用、结论可追溯性和必要披露。
- `project`：全部检查。
